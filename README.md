## ✦ Brand Color Architecture

- **Off-White Base / Surface**: `#FEFEFF` &mdash; Breathable, clean architectural off-white canvas.
- **Onyx Charcoal / Tech Dark**: `#252425` &mdash; High-contrast structural tone for body copy, dark blocks, and footers.
- **Electric Ultraviolet (Primary Glow)**: `#5336CC` &mdash; Vibrant signature accent for active customizer states, CTAs, and interactive vectors.
- **Muted Lavender Slate (Secondary Accent)**: `#8B77A4` &mdash; Subtle technical borders, CAD schematics, and typography accents.

---

## ✦ Key Pages & Store Architecture

- **Homepage (`index.html`)**:
  - Full-bleed atmospheric mountain peaks hero with oversized typography.
  - Floating 3D phone case flanked by orbiting basalt rock shards with GSAP mouse-follow parallax.
  - 4-Tier Trust Bar (`Premium Materials`, `MagSafe Compatible`, `Fast Shipping`, `Satisfaction Guarantee`).
  - 5-Column **Most Popular Cases** grid (`Matte Black`, `Stone Gray`, `Deep Blue`, `Sand Beige`, `Carbon Fiber`).
  - Dark statement split featuring close-up human hand holding case angled outward.
  - **On-Demand ("Create Your Own")**: Tilted custom case, sketched annotation `"Your Design Here"`, and 4-step process cards.
  - **Design Ideas Carousel**: 6 curated artwork cases (`Good Vibes Only`, `Topography Gold`, `Alpine Monochrome`, `White Marble`, `Geometric Fir Tree`, `Vibrant Geo Art`).
  - **From city streets to mountain peaks**: Dark cinematic mountain section with 4 tech feature callouts.
  - **Your Vision. Our Craft.** banner.
  - **About RON**: Hiker overlooking mountain ridges at dawn + high-contrast `#121214` footer with live UTC/Tokyo/SF/London studio clock.
- **Shop Catalog (`shop.html`)**: Full responsive grid with live category filters, device selectors, price sorting, dual-image hover crossfades, and quick-add to bag.
- **Interactive 3D Customizer (`customizer.html`)**: Real-time canvas/SVG customizer engine with device selection, materials, finishes, colorways, live foil monogram stamping, custom photo upload, 360° spinner, and 2K high-resolution snapshot exporter.
- **The Craft & Philosophy (`craft.html`)**: 16ft Mil-Spec drop test physics simulator, material breakdown, CNC tolerance blueprints, and artisan leather care.
- **Secure Checkout (`checkout.html`)**: Glassmorphic multi-step checkout with Express Pay, order summary, and promo code engine (`RON15`).

## ✦ Quick Start / Local Development

Run with Node (zero external dependencies required):

```bash
node server.js
```

Then visit [http://localhost:3000](http://localhost:3000) in your browser.

## ✦ Deploy to Vercel

### Option 1: One-Click Web Deployment
1. Go to [https://vercel.com/new](https://vercel.com/new).
2. Select your repository `waqaskakhtar-ui/Ron`.
3. Click **Deploy**. Vercel will automatically build and publish your store with edge caching and free SSL!

### Option 2: Vercel CLI
```bash
npm i -g vercel
vercel
```
